# LODEMISA

Sitio web estatico para portafolio/agencia, construido con HTML, CSS, JavaScript y recursos multimedia locales.

## Estructura

- `index.html`: pagina principal.
- `light.html`: pagina secundaria/galeria.
- `pagjavasscrio.html`: pagina adicional del proyecto.
- `estilo.css`, `lightbox.css`: estilos.
- `lightbox.js`: comportamiento de lightbox.
- `multimedia/`: imagenes, videos y audio usados por el sitio.

## Publicacion en GitHub Pages

1. Sube este repositorio a GitHub.
2. En GitHub, entra a `Settings > Pages`.
3. En `Build and deployment`, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Guarda los cambios.

GitHub publicara el sitio usando `index.html` como pagina inicial.

## Nota sobre archivos pesados

El proyecto incluye videos y recursos multimedia grandes. GitHub permite archivos de hasta 100 MB, pero recomienda mantenerlos por debajo de 50 MB para que el repositorio sea mas liviano.
